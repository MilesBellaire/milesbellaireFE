# Miles Bellaire Frontend

A responsive portfolio application showcasing professional experience and career history.

## Features

- **ExperienceBox**: Dynamic component for displaying work roles and responsibilities
- **WorkExperience**: Comprehensive career timeline with detailed job history
- **Mobile-optimized UI**: Works seamlessly across all device sizes
- **Fast performance**: Optimized for quick loading and smooth interactions

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the app.
